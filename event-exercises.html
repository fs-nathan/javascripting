06 Drag-and-Drop List Reordering

Kéo thả để sắp xếp lại các mục trong list.

  • Alpha
  • Bravo
  • Charlie
  • Delta
Drag items to reorder

Solution

list.addEventListener('dragstart', (e) => {
  e.target.classList.add('dragging');
});
list.addEventListener('dragover', (e) => {
  e.preventDefault();
  const after = getDragAfterElement(list, e.clientY);
  const dragging = list.querySelector('.dragging');
  if (!after) list.appendChild(dragging);
  else list.insertBefore(dragging, after);
});

15 Debounce Input Event

Debounce input 400ms trước khi “gọi API” giả.

Waiting...

Solution

function debounce(fn, ms) {
  let t;
  return (...args) => {
    clearTimeout(t);
    t = setTimeout(() => fn(...args), ms);
  };
}
input.addEventListener('input', debounce((e) => {
  out.textContent = 'API call: ' + e.target.value;
}, 400));

18 Fetch API with Error Handling

  const res = await fetch(url);
  if (!res.ok) throw new Error('HTTP ' + res.status);

}
