Mảng (Array) là danh sách các giá trị. Ví dụ:

```js
const pets = ['cat', 'dog', 'rat']
```

### Bài tập:

Tạo file tên `arrays.js`.

Trong file đó khai báo biến `pizzaToppings` tham chiếu mảng gồm ba chuỗi theo thứ tự: `tomato sauce`, `cheese`, `pepperoni`.

Dùng `console.log()` để in mảng `pizzaToppings` ra terminal.

Kiểm tra chương trình bằng lệnh:

```bash
javascripting verify arrays.js
```
