Số có thể là số nguyên như `2`, `14`, hoặc `4353`, hoặc số thập phân (float) như `3.14`, `1.5`, hoặc `100.7893423`.
Khác với Chuỗi (String), Số không cần dấu nháy.

## Bài tập:

Tạo file tên `numbers.js`.

Trong file đó khai báo biến tên `example` tham chiếu số nguyên `123456789`.

Dùng `console.log()` để in số đó ra terminal.

Kiểm tra chương trình bằng lệnh:

`javascripting verify numbers.js`
