**Chuỗi (String)** là dãy các ký tự. **Ký tự (Character)** là, nói đơn giản, một ký hiệu viết — chữ cái, số, dấu câu, khoảng trắng, v.v.

Giá trị chuỗi được bọc trong dấu nháy đơn hoặc nháy kép.

```js
'this is a string'

"this is also a string"
```

## LƯU Ý

Hãy nhất quán. Trong workshop này chúng ta chỉ dùng dấu nháy đơn.

## Bài tập:

Tạo file tên `strings.js`.

Trong file đó tạo biến tên `someString` như sau:

```js
const someString = 'this is a string'
```

Dùng `console.log` để in biến **someString** ra terminal.

Kiểm tra chương trình bằng lệnh:

`javascripting verify strings.js`
