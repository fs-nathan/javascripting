Bạn thường cần biết chuỗi có bao nhiêu ký tự.

Với việc này bạn dùng thuộc tính `.length`. Ví dụ:

```js
const example = 'example string'
example.length
```

## LƯU Ý

Đảm bảo có dấu chấm giữa `example` và `length`.

Đoạn code trên trả về **số (Number)** — tổng số ký tự trong chuỗi.


## Bài tập:

Tạo file tên `string-length.js`.

Trong file đó, tạo biến tên `example`.

**Gán chuỗi `'example string'` cho biến `example`.**

Dùng `console.log` để in **độ dài (length)** của chuỗi ra terminal.

**Kiểm tra chương trình bằng lệnh:**

`javascripting verify string-length.js`
