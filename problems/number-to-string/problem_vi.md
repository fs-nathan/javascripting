Đôi khi bạn cần chuyển số sang chuỗi.

Trong trường hợp đó dùng phương thức `.toString()`. Ví dụ:

```js
let n = 256
n = n.toString()
```

## Bài tập:

Tạo file tên `number-to-string.js`.

Trong file đó khai báo biến tên `n` tham chiếu số `128`;

Gọi phương thức `.toString()` trên biến `n`.

Dùng `console.log()` để in kết quả của `.toString()` ra terminal.

Kiểm tra chương trình bằng lệnh:

```bash
javascripting verify number-to-string.js
```
