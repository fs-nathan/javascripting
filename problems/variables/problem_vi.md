Biến (Variable) là tên tham chiếu đến một giá trị cụ thể. Biến được khai báo bằng `let` theo sau là tên biến.

Ví dụ:

```js
let example
```

Biến trên đã được **khai báo (declare)**, nhưng chưa được gán giá trị (chưa tham chiếu giá trị cụ thể).

Ví dụ gán giá trị cho biến:

```js
const example = 'some string'
```

# LƯU Ý

Biến được **khai báo** bằng `let` và dùng dấu bằng để **gán (define)** giá trị mà nó tham chiếu. Cách nói thông thường là "gán giá trị cho biến".

## Bài tập:

Tạo file tên `variables.js`.

Trong file đó, khai báo biến tên `example`.

**Gán cho biến `example` giá trị `'some string'`.**

Dùng `console.log()` để in biến `example` ra console.

Kiểm tra chương trình bằng lệnh:

`javascripting verify variables.js`
