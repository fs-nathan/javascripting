# 29. Đảo vị trí hai phần tử

Hoán đổi hai phần tử trong mảng theo chỉ số.

## Yêu cầu

Viết hàm `swapElements(arr, i, j)`.

- Trả về mảng mới (hoặc cùng mảng) sau khi đổi chỗ phần tử ở chỉ số `i` và `j`.

## Ví dụ

| Input | Output |
|-------|--------|
| `[1, 2, 3, 4], 0, 3` | `[4, 2, 3, 1]` |

## Gợi ý

Dùng biến tạm để hoán đổi.

## Cách nộp bài

Tạo file (ví dụ `swap-elements.js`) và export hàm:

```js
function swapElements (/* ... */) {
  // ...
}

module.exports = swapElements
```

Kiểm tra:

```bash
javascripting verify swap-elements.js
```
