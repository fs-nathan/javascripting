Đối tượng (Object) là danh sách giá trị tương tự mảng, nhưng giá trị được xác định bằng khóa (key) thay vì số nguyên.

Ví dụ:

```js
const foodPreferences = {
  pizza: 'yum',
  salad: 'gross'
}
```

## Bài tập:

Tạo file tên `objects.js`.

Trong file đó khai báo biến `pizza` như sau:

```js
const pizza = {
  toppings: ['cheese', 'sauce', 'pepperoni'],
  crust: 'deep dish',
  serves: 2
}
```

Dùng `console.log()` để in đối tượng `pizza` ra terminal.

Kiểm tra chương trình bằng lệnh:

```bash
javascripting verify objects.js
```
